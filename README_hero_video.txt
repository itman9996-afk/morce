راهنمای Hero ویدیویی Scroll-Driven
====================================

۱) کجا ویدیو را بگذارید؟
------------------------
فایل ویدیوی خود را در این مسیر قرار دهید:

  public/videos/hero.mp4        ← نسخه‌ی اصلی (الزامی)
  public/videos/hero-mobile.mp4 ← نسخه‌ی سبک‌تر موبایل (اختیاری؛ نبودش مشکلی ندارد،
                                   خود کامپوننت به‌طور خودکار به نسخه‌ی اصلی برمی‌گردد)
  public/videos/hero-poster.jpg ← فریم پوستر (اختیاری؛ برای پوشاندن لحظه‌ی لود اولیه)

پوشه‌ی public/videos را بسازید:
  mkdir public\videos   (ویندوز)
  mkdir -p public/videos (مک/لینوکس)

نام فایل ویدیوی شما فرقی نمی‌کند — کافی است پس از کپی، نامش را به hero.mp4 تغییر دهید،
یا مسیرها را در بالای components/sections/hero-video.tsx (ثابت‌های VIDEO_DESKTOP و
VIDEO_MOBILE و VIDEO_POSTER) ویرایش کنید.

۲) چطور کار می‌کند؟
------------------------
- بخش Hero ارتفاع 300svh دارد؛ داخل آن یک viewport استیکی (sticky top-0) با ارتفاع
  100svh قرار دارد که ویدیو را با object-fit: cover نشان می‌دهد.
- ویدیو هیچ autoplay / loop / play() ندارد؛ فقط currentTime آن کنترل می‌شود.
- اسکرول listener (passive) فقط targetProgress را به‌روز می‌کند.
- یک حلقه‌ی requestAnimationFrame با interpolation (ضریب 0.12) بین target و current،
  video.currentTime را نرم جلو و عقب می‌برد.
- 0% اسکرول = فریم اول | 100% اسکرول = فریم آخر | توقف اسکرول = توقف فریم.
- متن‌های Hero در 18% اولِ اسکرول به‌آرامی محو می‌شوند (بدون re-render، با style مستقیم).

۳) Fallback ها
------------------------
- اگر ویدیو لود نشود (مسیر اشتباه یا فایل خراب) → Hero قبلی (بصری) نمایش داده می‌شود.
- اگر prefers-reduced-motion فعال باشد → همان Hero ثابت، بدون ویدیو.
- اگر نسخه‌ی موبایل موجود نباشد → خودکار نسخه‌ی دسکتاپ لود می‌شود.

۴) بهینه‌سازی ویدیو (توصیه‌شده برای Seek روان)
------------------------
اگر ویدیو هنگام اسکرول پرش یا لگ داشت، با FFmpeg نسخه‌ی بهینه بسازید:

  ffmpeg -i input.mp4 -c:v libx264 -profile:v high -level 4.1 -pix_fmt yuv420p \
    -crf 22 -preset slow -g 24 -keyint_min 24 -movflags +faststart -an \
    -vf "scale=-2:1080" hero.mp4

نکات کلیدی:
- H.264 / MP4 با yuv420p (سازگاری کامل با همه‌ی مرورگرها)
- -g 24 → keyframe هر ۲۴ فریم (هر ثانیه) → Random Access سریع برای seek
- -movflags +faststart → شروع سریع پخش از وب
- -an → حذف صدا (صدا پخش نمی‌شود چون ویدیو muted است؛ حذفش حجم را کم می‌کند)
- نسخه‌ی موبایل: scale=-2:720 و crf 24

۵) چک‌لیست تست (Desktop و Mobile)
------------------------
[ ] ویدیو هنگام ورود به صفحه پخش نمی‌شود
[ ] اسکرول پایین → ویدیو جلو می‌رود
[ ] اسکرول بالا → ویدیو عقب برمی‌گردد
[ ] توقف اسکرول → فریم ثابت می‌ماند
[ ] کل ویدیو در کل محدوده‌ی Hero طی می‌شود (وسط Hero ≈ وسط ویدیو)
[ ] آخرین فریم دقیقاً در انتهای Hero است
[ ] بدون پرش بین Hero و بخش بعدی (بخش مسئله)
[ ] روان بودن در موبایل (iPhone و Android)
[ ] قطع اینترنت یا مسیر اشتباه ویدیو → Hero قبلی نمایش داده می‌شود

۶) تنظیمات ظریف (در hero-video.tsx)
------------------------
- LERP_FACTOR = 0.12 → نرمی حرکت؛ کمتر = نرم‌تر با تأخیر بیشتر، بیشتر = چسبیده‌تر به اسکرول
- ارتفاع بخش: کلاس h-[300svh] روی section
- سرعت محو شدن متن: عدد 0.18 در محاسبه‌ی fade
